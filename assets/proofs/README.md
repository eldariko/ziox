# Verified Proof Assets Repository (`assets/proofs/`)

This directory stores verified documentary and infographic assets used for fact-checking rebuttals on X:

## Categories
1. **Humanitarian Aid Data**: Verified COGAT reports, border crossing manifests, food tonnage statistics.
2. **Historical Documents**: League of Nations mandates, 1947 UN Partition Resolution 181, 1949 armistice agreements, Oslo Accords.
3. **Legal Documentation**: Law of Armed Conflict (LOAC) briefs, military target legal opinions.
4. **Infographics**: Clean, readable charts summarizing factual timelines and debunking recurrent viral disinformation memes.

## Guidelines
- All images or documents added here must be verified from primary or reputable sources.
- Filenames should follow lowercase snake_case (e.g., `cogat_aid_crossings_summary.jpg`).
